# Student Performance Portal

A simple academic dashboard for managing student performance, credit status, and promotion eligibility.

## What it includes

- Admin, Faculty, and Student login
- Role-based dashboards
- Credit calculation and promotion status
- Charts and progress indicators
- JWT auth for protected routes
- Mobile-friendly UI

## Stack

- React
- Vite
- Tailwind CSS
- Node.js
- Express
- MongoDB-ready backend

## Run it

1. Install dependencies:
   npm install
2. Start the backend:
   npm run start --workspace server
3. Start the frontend:
   npm run dev --workspace client
4. Open:
   http://localhost:5173
The API runs on http://localhost:5001.
